
RAMIJ Scientific Calculator is a command-line or GUI both  scientific calculator built using **C programming**,HTML,CSS,JAVA SCRIPT. The project provides an interactive terminal-based or GUI based interface for performing basic arithmetic, scientific calculations, and trigonometric operations.

## ✨ Features

* ➕ Addition
* ➖ Subtraction
* ✖️ Multiplication
* ➗ Division
* √ Square root
* x² Square
* x³ Cube
* Power calculation
* Logarithm (`log`)
* Natural logarithm (`ln`)
* Absolute value
* Sin, Cos, and Tan
* Interactive CLI menu
* Basic error handling
* Division-by-zero protection

## 🛠️ Technologies Used

* **C Programming**
* Standard C Library
* `math.h`
* GCC Compiler

## ⚙️ How to Run

### 1. Clone the repository

```bash
git clone https://github.com/YOUR-USERNAME/RAMIJ-Scientific-Calculator.git
```

### 2. Open the project folder

```bash
cd RAMIJ-Scientific-Calculator
```

### 3. Compile the program

```bash
gcc logic.c -o calculator.exe -lm
```

### 4. Run the calculator

On Windows:

```bash
.\calculator.exe
```

On Linux/macOS:

```bash
./calculator
```
